# Template Blade — Admin (Urbix) & Landing (iStudio)

Dhani Cahyo Kurnia Afandy 23670151

Layouting Blade untuk 2 template (masing-masing 6 halaman), dengan Controller dan Route terpisah untuk Admin dan Landing.

## Menjalankan

    composer install
    cp .env.example .env
    php artisan key:generate
    php artisan serve

## URL

Landing: `/`

Admin: `/admin/dashboard`
